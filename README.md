# NFL Injuries Project

This was my final project for STAT 437 Applications in Biostatistics. The main question we wanted to explore was whether or not the commonly held belief that 
injuries occur more often on turf fields was true. We found that injuries did NOT occur more frequently of turf fields than grass fields. We did find that
special teams plays like kickoffs did have a significantly higher rate of injuries that occur during them compared to normal offensive/defensive plays.
